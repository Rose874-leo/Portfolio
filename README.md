# Warda Toufeeq | Portfolio
https://warda-toufeeq.github.io/Portfolio/

My personal portfolio website. It shows who I am, my projects, my skills and a contact form.

## Features
- Responsive layout (works on phone and desktop)
- Dark mode button
- Project cards with links
- Contact form with JavaScript validation
- Smooth scrolling navigation menu

## Projects shown
- **To-Do App:** task manager with filters, edit and due dates
- **Titanic Survival Prediction:** Logistic Regression and Random Forest, about 81% accuracy
- **Iris Classification:** machine learning project using KNN

## Built with
- HTML
- CSS
- JavaScript (no libraries)

## How to run
Download the files and open `index.html` in your browser.
