# Warda Toufeeq | Portfolio
**Live site:** https://warda-toufeeq.github.io/Portfolio/
 
My personal portfolio website of an aspiring graphic designer and developer,
 It shows who I am, my projects, my skills and a contact form.

## Features
- Responsive layout (works on phone and desktop)
- Dark mode toggle
- Project cards with live demo and GitHub links
- Contact form with JavaScript validation
- Smooth scrolling navigation menu
